# OpenRappter (beta/) — Complete Feature Inventory

Source of truth: `beta/` on `sol/data-sloshing`, updated 2026-08-20. Version `0.1.0-beta.7`.

Conventions used below:
- `betaHome` = `$BRAINSTEM_BETA_HOME` or `~/.brainstem/beta-launcher` (`$BRAINSTEM_HOME` overrides `~/.brainstem`).
- `brainstemDir` = `$BRAINSTEM_BETA_SOURCE_DIR` or `~/.brainstem/src/rapp_brainstem`; `python` = `$BRAINSTEM_BETA_PYTHON` or `~/.brainstem/venv/bin/python`.
- `lineageRoot` = `$RAPP_LINEAGE_HOME` or `~/.rapp/lineage`.
- "Model?" = does exercising the feature end-to-end require a real GitHub Copilot model (Surgeon SDK session and/or the Grail kernel's `/chat` LLM call). "no (CLI)" = no model call, but the bundled Copilot CLI / sign-in must exist for the "ready" phase.
- "Static test" = the test reads source text with regexes (contract/lint style), it does not execute the behavior.
- Test references are `file: "test name"`; all under `beta/tests/`. Scripts are under `beta/scripts/`.

## 2. Complete `/drive` (UI driver bus) action catalog

Transport: `POST http://127.0.0.1:<port>/v1/command`, header `Authorization: Bearer <token>`, JSON body ≤ 256 KiB. `port`/`token` come from `betaHome/ui-driver.json` (`{version, host, port, token, pid, brainstemRuntimeFingerprint, runtimeFingerprint, startedAt}`). Response: `200 {ok:true, result}` (preceded by heartbeat spaces for long commands) or `400/401/404/503 {ok:false, error}`. Common top-level fields on any command: `target:"shell"` (drive the Electron shell frame instead of the Brainstem iframe), `twin:"<id>"` (drive that twin's iframe in the herd), `forceMode:true` + `forceLabel` (light force mode first), `idleMs` (re-arm force-mode auto-off).

UI Driver v2 metadata is `{version:2, host, port, token, pid, brainstemRuntimeFingerprint, runtimeFingerprint, startedAt, tracePath}`. Every caller (Rappter Surgeon, Python agent, external harness) enters the same queue keyed by visible frame (`brainstem`, `shell`, or `twin:<id>`). Every accepted command appends exactly `{action,handle,effect,snapshot_before,snapshot_after}` through credential redaction to that Frontier run's 0600 JSONL at `betaHome/logs/ui-driver-<run>.jsonl`; traces rotate at 5 MiB and retention keeps 20 inactive files for at most 14 days. Normal result payloads have a 6,000-byte default budget (override `byteBudget`, 512–65,536); truncation ends with `…(+N bytes — read handle:@x)`.

Common v2 fields: `target:"shell"` (default is the Brainstem iframe), `twin:"<id>"`, `handle:"@area.name"` / `"@list[key].part"` (preferred), legacy `selector` / `targetText`, `forceMode:true` + `forceLabel`, and `idleMs`. Handles must resolve to exactly one element; zero matches raise `UiDriverHandleNotFoundError`, multiple matches raise `UiDriverHandleAmbiguityError`. Fallback selectors are rooted at the nearest id/handle, never an unanchored tail.

Artifacts: `GET /v1/captures/<id>?token=<artifactToken>`, `GET /v1/recordings/<id>?token=…` (≤100 live entries). Upload: `OPTIONS|POST /v1/recording-upload?token=…` (`video/webm`, ≤500 MB, CORS `*`).

| Action | Where it runs | Params (defaults/bounds) | What it does / reads | Returns |
|---|---|---|---|---|
| `inspect` | target frame | `limit` 1–80 (60), optional `since:<snapshot>` | Builds a content-hashed accessibility outline; `since` returns added/changed rows plus removed rows marked `state:"removed"` | `{snapshot,frame,rows[{h,role,name,state}]}` |

## 5. Determinism blockers and existing stub/fake/replay facilities

### 5.1 Real model (GitHub Copilot)
- **Surgeon** uses a real Copilot SDK session by default. The regression harness sets
  `BRAINSTEM_BETA_SURGEON_RUNTIME=fake`, which loads scripted sessions (including a deterministic
  concurrent mode) without starting the bundled CLI.
- **Brainstem kernel `/chat`** still calls the unchanged Copilot surface. The harness pre-seeds the
  copied kernel's `.copilot_session` with a loopback endpoint served by `model-replay.mjs`, which
  supports replay, human-only record, and scripted stream/non-stream responses.
- Consequently every script in §1.12 except `show-mode-capture.mjs`, `walkthrough-gate.mjs`, `walkthrough-certify.mjs`, `package-gate.mjs` needs a signed-in Copilot and a live model; the walkthrough prompt relies on the model following six chapters and emitting exact markers (`FIVE_MINUTE_WALKTHROUGH_COMPLETE`, `LEARNED_AND_TAUGHT:RAPP_READY`, `STACK_CHURN_READY`, `UPDATE_STATUS=` …).
- Twin `loop()` requires two model chains (planner Brainstem + twin worker) plus regex detection of `DONE`/auth requests.

### 5.2 Network
- Store catalogs (AIBAST Pages registry, Frontier store, Public RAR, custom) and raw.githubusercontent singleton/egg/UI downloads — `RappStoreClient` takes `fetchImpl` (used by rapp-store.test with an in-memory `fakeStore`). Main uses Electron `net.fetch`; the store E2E switches the real picker to a sha-pinned loopback catalog.
- Update check/install: `git fetch` against GitHub (`runGit` injectable; update-manager.test passes fake git), `install.sh` downloads node tarballs + SHASUMS, npm registry, Electron.
- Molter (`AIBAST_REGISTRY` env in the agent), Agentic App Studio RAR fetches, PAC (`pac auth …`), Copilot Studio tenant.
- `frontier.sh/.ps1`: GitHub REST API + raw.
- Copilot CLI itself talks to GitHub.

### 5.3 Time
- Filenames embed ISO timestamps (`captures/brainstem-<iso>.png`, `recordings/brainstem-<iso>.webm`, walkthrough `run_id`, `.tmp` suffixes with pid).
- `createdAt` on rings (`LineageStore({now})` injectable; lineage-store.test uses a ticking fake), `createdUtc` on eggs (`packageAgent` uses `new Date()`; `tools/rapp1` vectors pin fixed UTC), telemetry timestamps, twin `createdUtc`, `startedAt` in `ui-driver.json`.
- Timers: cursor idle 4 s, force-mode idle 30 s, chat poll 150 ms, `wait` poll 100 ms, heartbeat 15 s, health wait 90 s (500 ms interval), `waitForWorkerIdle` 30 s, composition negative-cache TTL 60 s, recording auto-stop, walkthrough-gate "evidence is fresh" ≤ 6 h, "artifact created during this run" ±5 s, update-runner parent wait 120 s, log flush 5 s.
- `package-gate` "packaged app is newer than beta source" compares mtimes.

### 5.4 Randomness / identity
- `randomUUID` for caller/stack RAPPID anchors (`mintRappid` accepts `uuidAnchor`), ephemeral composition nonce, chat-lease tokens, staging dir names; `randomBytes` for driver tokens and artifact ids; twin ids `<slug>-<seq>` (per process), Surgeon ids (renderer seq, persisted). Lineage ring/ancestor ids are deterministic (content + filename).
- `compositionHash` is deterministic for a given identity + bytes; `identity.json` makes every install unique — a fresh `BRAINSTEM_BETA_HOME` yields a fresh RAPPID/memory GUID.

### 5.5 Ports / processes
- Workers and twins use OS-allocated loopback ports. Normal `BrainstemProcess` startup may reuse a
  healthy configured server; `BRAINSTEM_BETA_OWN_PORT=1` skips adoption and owns a newly allocated
  loopback port. The UI-driver port is random and read from metadata.
- Orphaned twin/worker processes from a crashed session are not reaped (only their dirs are wiped).
- Agentic App Studio spawns `serve.py`; PAC/ffmpeg/ffprobe/git/python are external executables (`BRAINSTEM_BETA_FFMPEG`, `BRAINSTEM_BETA_FFPROBE`, `BRAINSTEM_BETA_PAC`, `BRAINSTEM_BETA_GIT_EXE`, `BRAINSTEM_BETA_NODE_EXE`, `BRAINSTEM_BETA_PYTHON` overrides).
- Electron single-instance lock: a second launch with the same user data dir exits.
