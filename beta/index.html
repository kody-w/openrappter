Full OpenRappter desktop

Run the full OpenRappter organism on your desktop.

OpenRappter is the fully built-out twin; Brainstem is the bare twin. They share the `/chat` wire while keeping separate identity, state, worker ports, backups, and lifecycle. Install the OpenRappter desktop application from one immutable GitHub release commit. It includes Rappter Surgeon, the local Brainstem runtime, your agents, memory, tiles, and visible automation.

Builder preview, not production.

Use synthetic or approved data. Validate the proof with a human, then move production identity, connectors, governance, telemetry, and scale into the selected platform.
