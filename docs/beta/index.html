openrappter · v3 beta

The drill, running here

Machines normally redo work other machines already did. This finds work someone else already finished, checks it cannot invalidate anything you built on, and absorbs it. It does not create capability — it stops capability that already exists from being lost.

This page runs the code that ships. Not a demonstration written to look like it. qqdrill.mjs and the RAPP/1 frame spec are loaded unmodified from the repository; only SHA-256 is supplied by the browser, because the protocol hashes synchronously and Web Crypto does not. A test fails the build if this copy ever drifts from the shipped one.

Start openrappter on your machine

This page shows the method. The one-liner installs and launches the desktop application, which runs the same code against your own lines instead of a fixture.

curl -fsSL https://raw.githubusercontent.com/kody-w/openrappter/main/beta/install.sh | bash

Installs a pinned Node runtime of its own, so a machine with no developer tools works. Nothing is installed system-wide.

03What just happened



  
TermWhat it means

  
fixed pointThe same bytes reached along a different history. It pins the two lines against each other, so everything around it lines up by arithmetic rather than guesswork.

  
runHow many ticks matched in a row. Longer is stronger evidence — one match can be coincidence, six cannot.

  
mergedAbsorbed. It could not invalidate anything you had already built on.

  
refusedTurned away, with the reason. Something on your line declared it depended on a fact this frame contradicts.

  
checkpointA copy taken before the fold. There is no un-merge, so there is a way back.
