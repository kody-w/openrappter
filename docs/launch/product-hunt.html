First comment (maker) 

Hi Product Hunt. I'm Kody. I talk to my computer for a living, so I wanted something on my Mac I could talk to the way I'd talk to a person sitting next to me, without opening an app.

OpenRappter lives in the notch. Hold ⌥ Space and talk; it answers out loud. Hold ⌃⌥ Space and it types what you said wherever your cursor is. Hold ⇧⌥ Space and it reads the window in front of you and answers about it.

When something needs you, it changes posture and waits. If you use Claude Code, its permission prompts show up in the notch with Allow once, No, Always, so you answer from wherever you are.

Three decisions I'm proud of:
• It thinks through the GitHub Copilot sign-in you already have. No new API keys, no new bill.
• There's no cloud computer. The brain is an open RAPP Brainstem kernel running on your Mac as a login service, and the app only talks to it through three plain HTTP calls (health, chat, sign-in), so you can read everything it does. What you ask, and the text of a window you ask about, goes to GitHub Copilot through your own sign-in.
• It never invents a need and it never speaks first. Tamagotchi, not Clippy.

MIT licensed. Signed and notarized. macOS 14+.
