v1.13.0 · 2026-08-14

Show it once.
Keep the judgment.

OpenRappter can now learn a workflow from a real local demonstration, reconstruct the intent and ordered steps, let you correct the result, and package the approved procedure as a portable skill or a disabled automation.

Record

Context, not surveillance

The detached collector records active app/window changes, privacy-reduced browser destinations, notes, and OpenRappter actions. Screenshots are explicit-only; typed text is never persisted.

Review

The human owns the procedure

Deterministic local analysis comes first. Optional Copilot refinement receives only a separately approved textual summary—never raw frames. Approval itself requires a one-use local token.

Reuse

Native tools over pixel replay

Build a cross-runtime SKILL.md and manifest, a disabled automation, or both. Replay is a dry run and generated artifacts are hash- and privacy-checked before they are trusted.

A consent boundary for every irreversible edge

  • ✓ recording starts only from an interactive local terminal
  • ✓ Copilot enhancement has separate disclosure and consent
  • ✓ approval is local, short-lived, and single-use
  • ✓ deletion requires a fresh local confirmation
openrappter show-and-tell start --intent "Publish a release"
openrappter show-and-tell note "Wait for every required check"
openrappter show-and-tell stop
openrappter show-and-tell analyze
openrappter show-and-tell approve
openrappter show-and-tell build --target all
openrappter show-and-tell test

Desktop

Skill Recorder ergonomics, one OpenRappter core

The new Electron shell launches or reuses the same local gateway and loads its own packaged current UI. Its renderer is sandboxed and context-isolated; native dialogs guard recording, scoped window capture, approval, and deletion. Electron carries an isolated packed runtime and SQLite binding, so the system Node installation is never rebuilt.

Chat can now drive that visible UI through semantic snapshots and refs, and approved Python or TypeScript agents can return the same bounded UI commands. Whisper handles local narration; VibeVoice Realtime 0.5B handles optional local speech; Electron's tray and the Swift OpenRappter Bar attach to one authenticated desktop gateway.

Evidence, not launch copy

The release gate runs TypeScript and Python unit suites, npm test, pytest, builds, lint, package installation smoke, cold-start CLI smoke, native detached-worker probes, and a cross-runtime SQLite handoff. Artifact integrity is verified with SHA-256, while privacy mutation tests keep consent and redaction behavior executable.
